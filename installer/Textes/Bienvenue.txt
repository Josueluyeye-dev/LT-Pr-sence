CET ASSISTANT VA :
  • Installer l'application dans le dossier de votre choix

  • Proposer un raccourci sur le Bureau (optionnel).

VERSION PORTABLE .NET
  Cette édition inclut le runtime .NET nécessaire : vous n'avez
  pas besoin d'installer .NET séparément sur le poste.

PRÉREQUIS
  • Windows 10 ou Windows 11 (64 bits)
  • Droits administrateur pour une installation sous Program Files
  • Accès réseau aux pointeuses ZKTeco (selon votre déploiement)

CONSEIL (IMPORTANT EN MISE À JOUR)
  Fermez LT Services Présence (icône dans la barre des tâches)
  avant de poursuivre. L'installateur arrête aussi le worker
  pointeuse ZKTeco pour éviter l'erreur « Accès refusé » sur
  les fichiers DLL (ex. System.Text.Json.dll).
